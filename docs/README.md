# 👋 Welcome to Reviews Analyzer

**Reviews Analyzer** is an automated tool designed to aggregate and analyze user feedback from multiple app ecosystems into a single, actionable dashboard. 

In a world where user feedback is scattered across mobile stores and smart TV platforms, this tool provides a "Single Source of Truth" for Product Managers and Developers.

## Key Features
*   **Multi-Platform Support:** Aggregate reviews from Google Play, Apple App Store, Roku, and more.
*   **AI Sentiment Analysis:** Automatically categorize reviews as positive, negative, or feature requests using LLMs (Gemini/Ollama).
*   **Historical Tracking:** Monitor how app ratings trend over time after new releases.
*   **Unified Dashboard:** Search and filter reviews across all platforms in one place.

## Why this project?
Most analytics tools focus solely on mobile (iOS/Android). This project expands that focus to include the often-overlooked **Smart TV ecosystem**, helping developers understand the unique challenges of big-screen applications.
